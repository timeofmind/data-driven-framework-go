# data-driven-framework-go

A data-driven framework for Go: one YAML description of your data structures,
relationships and rules is the single source of truth, and every data endpoint —
database tables, web forms, APIs, docs — is derived from it.

This is a Go port of [data-driven-framework-perl](https://github.com/timeofmind/data-driven-framework-perl).
Schemas written for the Perl framework load unchanged; the Go port adds a few
optional extensions (below) needed to run public, multi-user web applications.

```
YAML schema files
      │
schema.Parse ──► schema.Resolve ──► schema.Validate      (schema.Load does all three)
      │
model.Model  (canonical in-memory model)
      │
 ┌────┴─────┬─────────┬────────────┬──────┬──────┬──────────┬─────────┐
SQL      Migration  OpenAPI   JSON Schema   UI    Docs    Runtime    Sandbox
(MySQL,  (diff)                                          (CRUD,      (temp DB +
 SQLite)                                                  access)     fixtures)
```

## Packages

| Package | Purpose |
|---|---|
| `model` | Classes, slots, enums, relationships, constraints; naming rules; type maps |
| `schema` | YAML parsing (multi-file merge), inheritance resolution, semantic validation |
| `dialect` | MySQL/MariaDB (reference, same DDL as the Perl framework) and SQLite |
| `generator` | DDL, migrations, OpenAPI 3.0.3, JSON Schema draft-07, UI config + HTML scaffold, Markdown docs |
| `diff` | Schema comparison (create/drop table, add/drop/modify column, unique keys) |
| `runtime` | `Registry` + per-class `Handle`: List/Count/Load/Save/Delete, joined-table inheritance, relationship navigation, input coercion and validation, access rules, password hashing, safe auto-migration |
| `reverse` | Build a YAML schema from an existing MySQL or SQLite database |
| `sandbox` | Throwaway SQLite database with fixtures, for tests |
| `cmd/ddframework` | The CLI |

## Quick start

```yaml
# schema/app.yaml
schema_version: "1.0.0"
enums:
  Status: {values: [active, inactive], default: active}
classes:
  User:
    slots:
      - {name: id, type: integer, autogenerated: true, read_only: true, required: true}
      - {name: username, type: string, required: true, max: 40, pattern: '^[a-z0-9_]+$'}
      - {name: status, type: enum, enum: Status, default: active}
      - {name: created_at, type: datetime, autogenerated: true, read_only: true}
    constraints:
      unique: [username]
```

```sh
go install github.com/timeofmind/data-driven-framework-go/cmd/ddframework@latest
ddframework validate --schema schema/app.yaml
ddframework generate-sql --schema schema/app.yaml --dialect mysql --output schema.sql
ddframework generate-openapi --schema schema/app.yaml --output openapi.yaml
ddframework ensure-schema --schema schema/app.yaml --driver sqlite --dsn app.db
```

```go
reg, err := runtime.FromSchema("sqlite", "app.db", "schema/app.yaml")
if err != nil { ... }
if _, err := reg.EnsureSchema(ctx); err != nil { ... }   // creates tables / adds columns, never drops

users := reg.MustClass("User")
u := users.New(nil)
if errs := u.Assign(formValues); errs != nil { ... }      // coerces untrusted input, writable slots only
if err := users.Save(ctx, u); err != nil { ... }          // validates (required, enum, min/max, pattern)

active, err := users.List(ctx, runtime.Query{
    Where:   []runtime.Cond{runtime.Eq("status", "active")},
    OrderBy: "created_at desc",
    Limit:   20,
})
```

## CLI

```
ddframework <command> [options]
  validate              Validate a schema file
  generate-sql          Generate DDL (--dialect mysql|sqlite)
  reverse-from-db       Generate YAML schema from an existing database
  generate-openapi      Generate OpenAPI 3.0 spec (--format yaml|json)
  generate-json-schema  Generate JSON Schema definitions
  generate-ui           Generate UI scaffold (JSON config + HTML, regenerates between markers)
  generate-docs         Generate Markdown documentation
  diff                  Compare two schema versions (--sql for a migration script)
  migrate               Apply a migration SQL file
  ensure-schema         Create missing tables/columns in a database (never drops)
  init-project          Initialize a new project skeleton
  sandbox-info          Load a schema (+ fixtures) into a temp SQLite sandbox and report
  version               Show version information
```

## Schema format

Top level: `schema_version`, `framework_version`, `description`, `enums`, `classes` —
exactly as in the Perl framework. Multiple files merge; later files override earlier
ones per class and per enum.

**Class attributes:** `label`, `description`, `table` (default: snake_case plural),
`abstract`, `is_a` (joined-table inheritance, any depth), `slots`, `relationships`
(`belongs_to` / `has_many` / `many_to_many`), `constraints` (`unique`, `indexes`).

**Slot attributes:** `name`, `type` (`string integer float boolean date datetime text enum`),
`enum`, `required`, `default`, `autogenerated`, `read_only`, `api_read_only`, `hidden`,
`label`, `description`, `placeholder`, `control_type`, `ui_order`, `ui_group`, `min`,
`max`, `pattern`.

Every `belongs_to` gets an inverse `has_many` on the target automatically.

### Go-port extensions (all optional)

| Where | Attribute | Meaning |
|---|---|---|
| slot | `type: password` | Stored as a bcrypt hash; accepted on input, never emitted in records, APIs or forms |
| slot | `type: duration` | Whole seconds in the database and API; entered and shown as `h:mm:ss` (also accepts `mm:ss`, `1h20m`) |
| class | `display: slot` | Slot used as the record's title in links and selectors |
| class | `order_by: "slot desc"` | Default list ordering |
| class | `calendar: date_slot` | Front ends may render a calendar view on this date |
| class | `auth: {login, password, display}` | Marks the class whose rows are login principals |
| class | `access: {owner, read, write, public_when}` | Row ownership and visibility, enforced by `runtime.Scope` / `CanRead` / `CanWrite` |
| belongs_to | `on_delete: cascade \| set_null \| restrict` | Foreign-key delete behaviour |
| has_many | `order_by: "slot asc"` | Ordering when navigating the relationship |

`access.read` is `public` (default), `authenticated` or `owner`; `access.write` is
`owner` (default when an owner slot is set), `authenticated` or `nobody`.
`public_when: {visibility: public}` makes matching rows readable by anyone even when
`read: owner`.

## Differences from the Perl framework

- SQLite dialect alongside MySQL/MariaDB (enums become `CHECK` constraints).
- Joined-table inheritance works to any depth; inherited relationships resolve.
- `diff` compares only the columns a joined-table child actually stores.
- Classes are ordered so `belongs_to` targets are created before referencing tables.
- The runtime validates and coerces values (the Perl runtime stored them as given).
- Many-to-many navigation is supported read-side, as in Perl.

## Tests

```sh
go test ./...                                    # SQLite
DDF_TEST_MYSQL_DSN='user:pw@unix(/run/mysqld/mysqld.sock)/scratch' go test ./...   # + MySQL/MariaDB
```

The MySQL tests drop every table in the target database — point them at an empty
scratch database.
